# 工作记忆 · iPhone 独立版

用户在 2026-10-22 澄清：手机必须独立完成录音、转写、分析、整理。Mac 同步为下一阶段，不是使用前提。原始需求保留在 ORIGINAL_PRD.md，冲突处以本文件和用户最新指示为准。

## 本次闭环

1. 主动开始场景录音，原生 AVFoundation、后台音频、暂停/继续、5/10/15 分钟分段，音频先写入手机。
2. 结束后仅保存，或由用户明确确认“发送并分析”。录音中不发送音频。
3. 手机直接通过 HTTPS 连接配置的 AI 服务，不依赖 Mac 或个人电脑开机。
4. 每个音频分段独立转写；已完成分段缓存到手机，失败后主动重试只补缺失分段。
5. 基于原文生成摘要、观点、判断方法、案例、决策、待办、跟进问题和有原文依据的选题。选题可生成口播初稿。
6. 所有结果本地保存，可编辑、搜索、收藏、导出和删除。
7. 没有 AI 凭证也能完整录音；分析时说明如何在“设置→AI 服务”配置。

## 服务与隐私

首版实现 OpenAI 格式的 HTTPS API：audio/transcriptions 和 chat/completions。默认语音模型 gpt-transcribe，默认文字模型 gpt-4.1-mini；模型和地址可调整。非兼容服务不能仅改名称即接入。

个人自用采用自带服务凭证，使用 iOS Keychain（本机、首次解锁后可用）存储；普通设置和录音导出不含凭证。音频/文字只在用户确认目标服务后发送。应用不内置共享密钥。分发给多人前应改为独立的凭证代理或短时授权设计。

服务端数据保留由所选服务政策决定；删除手机文件不等于删除服务商的数据。使用在线服务需要联网和对应 API 额度，ChatGPT 订阅不能当作 API 凭证。开发时不读取用户其他软件的密钥，不自动发起真实付费调用。

分析在前台执行，进入后台会暂停并取消当前请求，恢复前台后需主动重试。已经持久化的成功步骤不会重发；请求已到服务端但本地未收到结果时无法保证重试零重复计费，界面必须告知。不得宣称 iOS 允许无限后台 AI 运行。

当前语音模型的基本 JSON 返回不含精确句级时间戳，因此来源定位到原始音频分段，清楚标注“分段起点”，不伪造句子时间。
