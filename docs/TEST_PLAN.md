## 真机待验（不得以模拟器代替）

- [ ] 麦克风允许/拒绝/设置后重试。
- [ ] 开始→暂停→继续→结束，暂停期间不采音。
- [ ] 30分钟锁屏、60分钟连续录音、自动分段间隙和耗电。
- [ ] 来电、Siri、耳机断开、媒体服务重置。
- [ ] 强制结束后重启，早前分段可播放，损坏末段保留可导出。
- [ ] 空间不足时安全停止；飞行模式录音无影响。
- [ ] 配置真实 HTTPS 服务，确认发送目标后中文转写、摘要、引用与初稿。
- [ ] 网络断开，成功分段已缓存；失败时可重试、不自动循环计费。
- [ ] 进入后台取消 AI，回前台保留结果并提示手动继续。
- [ ] 真实 AI 长录音分批处理、超限和拒绝输出提示。
- [ ] 删除前确认，分析中禁止删除；导出不含服务凭证。

## 已知限制

没有内置 API 账户或额度。在线 AI 需要用户配置可访问的兼容服务和凭证；具体服务的地域可用性、额度、数据政策由用户账户决定。句级精确时间戳不是当前普通转写协议的保证，仅提供音频分段起点。后台暂停时服务端可能已经处理请求，重试不能承诺绝不重复计费。
